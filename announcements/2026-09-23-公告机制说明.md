# 欢迎使用桌上英雄联盟

这是一份示例公告，用于说明公告机制怎么用。

## 发布新公告的方法

1. 在本目录（`announcements/`）新增一个 Markdown 文件；
2. 文件名以日期开头：`YYYY-MM-DD-标题.md`（例如 `2026-10-01-2.6.0 版本发布.md`）；
3. 推送到 main 分支即生效——应用端取**文件名排序最大**的 `.md` 作为当前公告。

## 约定

- 应用端把正文当纯文本渲染（保留换行），支持 `# 标题` 作为公告标题；
- `README.md` 不参与公告排序；
- 应用拉取失败时会展示上一次成功的内容，不会报错打扰。
