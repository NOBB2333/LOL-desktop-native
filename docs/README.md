# 文档地图

先看这里，再决定读哪份。

## 命名规则

文件名本身就标出了文档属于哪一类：

| 目录 | 是什么 | 会不会更新 | 命名 |
|---|---|---|---|
| [`design/`](design/) | 现行约定 | **会**，随时追加 | `主题.md`，不带日期 |
| [`reports/`](reports/) | 阶段性报告 | 不会，写完即定型 | `主题_YYYY-MM-DD.md` |
| [`archive/`](archive/) | 历史归档 | 不会，部分结论已被推翻 | `主题_YYYY-MM-DD.md` |
| [`changes/`](changes/) | 变更记录 | 每个版本追加 | `CHANGELOG.md` |

`reports/` 与 `archive/` 的日期是**正文写成那天**，不是文件被移动的日期；
`design/` 不带日期，因为它一直在长（「界面不变量」到今天还在追加条目）。
